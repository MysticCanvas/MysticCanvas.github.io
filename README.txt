Canvas-Mystic Complete Store

This package contains the upgraded GitHub Pages store with the artwork files previously created for the Canvas-Mystic project.

Publish:
1. Upload/replace index.html, fantasy-logo.png, and the assets folder in the MysticCanvas/MysticCanvas.github.io repository.
2. Keep the repository public and GitHub Pages enabled from the main branch/root.
3. The site will use the existing TeePublic store: https://www.teepublic.com/user/canvas-mystic

Note: Individual TeePublic product URLs were not invented; every artwork button safely opens the real Canvas-Mystic TeePublic storefront.
